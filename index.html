LeakX is a smart water monitoring project focused on making water-use information easier to understand and helping bring attention to possible leaks. It explores how technology can support more informed, water-conscious decisions.

Project goals

Designed around better water awareness.

LeakX aims to make monitoring more approachable. Specific functions depend on the sensors, hardware, and software implemented in the repository.

◉

Water-use monitoring

Organize water-flow or consumption readings so users can better understand usage, when supported by connected sensors.

⌁

Leak awareness

Explore ways to flag unusual flow or sensor events through suitable detection rules and alerts.

▤

Readable information

Present important readings and status in a clear format that can be extended as the project develops.
